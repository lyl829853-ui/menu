# 🍔 منيو احترافي وحديث

## 📋 نظرة عامة
مشروع منيو ويب احترافي وحديث مبني بـ React و TypeScript مع دعم كامل للعربية والإنجليزية.

## ✨ الميزات
- ✅ **تصاميم متعددة**: مظاهر فاتحة وداكنة
- ✅ **مرونة في الاتجاه**: قوائم أفقية وعمودية
- ✅ **قوائم متداخلة**: دعم كامل للـ Nested Menus
- ✅ **أيقونات وشارات**: Badge support + custom icons
- ✅ **TypeScript**: نوع آمن بالكامل
- ✅ **Responsive**: يعمل على جميع الأجهزة
- ✅ **Accessibility**: معايير WCAG
- ✅ **الحركات السلسة**: انتقالات وحركات احترافية

## 🚀 البدء السريع

### الخطوة 1: استنساخ المشروع
```bash
git clone https://github.com/lyl829853-ui/menu.git
cd menu
```

### الخطوة 2: تثبيت المتطلبات
```bash
npm install
```

### الخطوة 3: تشغيل خادم التطوير
```bash
npm run dev
```

سيتم فتح الموقع تلقائياً في متصفحك على `http://localhost:3000`

### الخطوة 4: البناء للإنتاج
```bash
npm run build
```

هذا سينشئ مجلد `dist` يحتوي على الملفات المحسَّنة للإنتاج.

## 📁 هيكل المشروع
```
menu/
```

## 💻 الاستخدام

### استخدام المنيو في مشروعك
```jsx
import Menu from './components/Menu'

const menuItems = [
  {
    id: '1',
    label: '🏠 الرئيسية',
    href: '/'
  },
  {
    id: '2',
    label: '📚 الخدمات',
    href: '/services',
    children: [
      { id: '2-1', label: 'خدمة 1', href: '/services/1' },
      { id: '2-2', label: 'خدمة 2', href: '/services/2' }
    ]
  }
]

function MyComponent() {
  return (
    <Menu 
      items={menuItems}
      orientation="horizontal" // أو "vertical"
      theme="light" // أو "dark"
    />
  )
}
```

## 🎨 التخصيص

### تغيير الألوان
عدّل متغيرات CSS في `src/styles/global.css`:
```css
:root {
  --primary-color: #007bff;
  --primary-hover: #0056b3;
  /* ... المزيد من الألوان ... */
}
```

### إضافة عناصر جديدة
أضف عناصر جديدة إلى مصفوفة `menuItems` في `App.jsx`
